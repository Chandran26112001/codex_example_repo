# codex_example_repo

This repository is a small example project for demonstrating GitHub workflows with Codex.

## Fibonacci program

Run the program and enter the number of Fibonacci terms to print:

```bash
python3 fibonacci.py
```

For example, entering `7` prints:

```text
Fibonacci series: 0 1 1 2 3 5 8
```

The input is the number of terms to generate and must be a positive whole number.
